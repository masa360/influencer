# AI広報アシスタント 運用の手引（お客様向け）

導入ありがとうございます。この手引は、**毎日の使い方** と **困ったときの対応** をまとめたものです。

## このアシスタントができること・できないこと
| できること | できないこと |
|---|---|
| LINE（とサイトのチャット）に届いたメッセージへ、24時間自動で返信する | フォロワーや問い合わせを増やすこと（入口の集客はこれまでどおり必要です） |
| 相談に進みそうな方を見つけて、あなたのLINEにお知らせする | 予約の確定・契約・成約（最後はあなたが対応します） |
| 返金・解約・クレームなどは返信せず、あなたに回す | 専門的な判断（法律・医療・投資など）の保証 |
| 受信内容をスプレッドシートに全件記録する | 内容が100%正しいことの保証（AIは間違えることがあります） |

## 最初の1〜2週間は「下書きモード」
- AIは返信案を作るだけで、**あなたが承認するまで送信しません**。
- 毎日、受信ログを開いて、返信案を確認して「この内容で送信」を押してください（直してから送ることもできます）。
- 問題が出ない状態が続いたら、「全自動」に切り替えます（切り替えは、担当者にご相談ください）。

## 毎日の流れ
1. **LINEの通知を見る**：次の通知が届きます。
   - 🔥 **見込み客**：相談に進みそうな方が来ました。早めに対応してください。
   - 🙋 **要人間対応**：返金・解約・クレームなど。**AIは返信していません**。あなたが直接対応してください。
   - ⚠️ **返信エラー**：AIが返信できていません。担当者に連絡してください。
2. **アプリを開く**（URL・管理トークンは別途お渡しします）→「自動返信」タブ →「受信ログ・承認キュー」
3. **「承認待ち」を確認** → 返信案を読んで「この内容で送信」（直したいときは、文章を直してから送信）
4. **「要人間対応」の方へ、あなたから連絡する**

## すぐ止めたいとき
アプリの画面の一番上にある **「緊急停止する」** を押すと、すべての自動返信が止まります。もう一度「自動返信を開始する」で再開できます。

## ご注意いただきたいこと
- **「公式のAI」と明記してください**：SNS・LINEのプロフィールに「〇〇公式のAI広報アシスタント」と書いてください。AIが一般のお客様や無関係の第三者のふりをすると、いわゆる「ステマ規制」の対象になるおそれがあります。
- **実績・数字は事実だけ**：アプリに入力する「強み・実績」は、根拠のある内容だけにしてください。AIはその範囲でしか話しません。
- **AIの返信を信じすぎない**：金額・条件・納期などの約束にかかわる内容は、必ず人が確認してください。
- **個人情報**：受信ログには、お客様の見込み客の個人情報が含まれます。管理トークンやスプレッドシートは、関係者以外に共有しないでください。管理トークンは、人に見える場所（チャットやメール）に書かないでください。
- **「返信がおかしい」と思ったら**：その会話のキャプチャを添えて、担当者に連絡してください。AIへの指示（口調・禁止事項）を直せます。

## 設定を変えたいとき
次は、担当者にご連絡ください。
- キャラの口調・名前、ボス情報（実績・誘導先）の変更
- 「人間が対応するキーワード」の追加
- 通知を受け取る担当者の追加・変更
- 全自動への切り替え／下書きモードへの戻し

## 解約するとき
担当者にご連絡ください。受信ログの控えをお渡しし、ご了承いただいたうえで、サーバーとデータを削除します。あわせて、Gemini と LINE の鍵の無効化（再発行）をお願いします。
